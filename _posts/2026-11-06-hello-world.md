## How this site works

The site is built with [Jekyll](https://jekyllrb.com/) and hosted for free on GitHub Pages. Every post is a Markdown file in the `_posts` folder. Pushing to the `main` branch publishes it automatically.

A post file is named `YYYY-MM-DD-slug.md` and starts with a small header:

```yaml
---
title: "My post title"
date: 2026-11-06 10:00:00 -0800
tags: [example]
---
```

Everything below the header is regular Markdown. You can add a `<!--more-->` line to mark where the excerpt ends.
