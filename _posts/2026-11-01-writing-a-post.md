## Headings and text

Use `##` for section headings. **Bold**, *italic*, and `inline code` all work. Here is a [link](https://github.com).

## Lists

1. Create a file in `_posts`
2. Give it a date-prefixed name
3. Commit and push

- Bullets work too
- And nest
  - like this

## Images

Put images in `assets/images/` and reference them like this:

```markdown
![Alt text](/assets/images/photo.jpg)
```
